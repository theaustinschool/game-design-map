# Context

## Glossary

**Note**
A single unit of written thought in the collection. Covers both a Matuschak *evergreen note* and a zettelkasten.de *zettel*. The Rulebook decides how far the two coincide.
_Avoid_: card (unless the source means paper)

**Rulebook**
The destination artifact. It is a numbered set of Rules for building a good Note.

**Rule**
One operational instruction in the Rulebook. A Rule must be checkable: given a Note, a human or an agent can decide whether the Note passes or fails it without a judgment call the Rule leaves open. Every Rule cites the Claims it rests on.

**Claim**
One atomic statement, taken from a source, about what makes a Note good or how to build one. Recorded as a row in a Claim ledger with a verbatim quote and URL. A Claim is evidence, while a Rule is a decision.

**Claim ledger**
The table of Claims that one gather ticket produces, together with that ticket's coverage log. See `research/README.md`.

**Conflict**
Two or more Claims that would produce incompatible Rules. Gatherers record Conflicts; grilling resolves them.
